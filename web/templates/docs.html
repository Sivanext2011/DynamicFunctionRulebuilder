Examples from Production CHA Systems

Example 1: Determine Service Scenario (MMTel/Voice)

Voice IMS Routing

Determines the service scenario based on service type and role of node for IMS voice calls.

Function: DetermineServiceScenarioMMTel

Input: ServiceType (Long), RoleOfNode (Integer)
Output: ServiceScenario (String)

If ServiceType is 6 then set ServiceScenario to Forwarding and exit
If RoleOfNode is 0 then set ServiceScenario to MobileOriginating and exit
If RoleOfNode is 1 then set ServiceScenario to MobileTerminating and exit
Default set ServiceScenario to Unknown
Example 2: Determine Retarget Address (Announcement Routing)

Announcement Retarget Error Handling

Routes to different announcement addresses based on result code and announcement code.

Function: DetermineRetargetAddress

Input: ResultCode (Long), CoreAnnouncementCode (Long)
Output: RetargetAddress (String)

If ResultCode is 4012 and CoreAnnouncementCode is 1934 then set RetargetAddress to 8321 and exit
Otherwise set RetargetAddress to 8342
Example 3: Normalize Roaming Position

Roaming MCC/MNC Location

Determines roaming position by comparing serving and home MCC/MNC values.

Function: DetermineRoamingPosition

Input: servingMccMnc (String), homeMccMnc (String)
Output: roamingPosition (String)

If servingMccMnc equals homeMccMnc then set roamingPosition to HOME and exit
Default set roamingPosition to ROAMING
Example 4: Determine Charging Profile

Charging Rating Multi-output

Assigns charging profile, rating group and service identifier based on service type and role.

Function: DetermineChargingProfile

Input: serviceType (Long), roleOfNode (Integer), roamingIndicator (Boolean)
Output: chargingProfile (String), ratingGroup (Integer), serviceIdentifier (String)

If roamingIndicator is 1 then set chargingProfile to RoamingDefault and exit
If serviceType is 6 then set chargingProfile to Forwarding and exit
If serviceType is 10 then set chargingProfile to SMS and exit
If roleOfNode is 0 then set chargingProfile to MobileOriginating and exit
If roleOfNode is 1 then set chargingProfile to MobileTerminating and exit
Default set chargingProfile to Default
Example 5: Suppress First Update CDR

CDR Suppress Session

Determines whether to suppress the first update CDR based on request type.

Function: SuppressFirstUpdateCDR

Input: requestType (Integer), requestNumber (Integer)
Output: suppressCDR (String)

If requestType is 1 and requestNumber is 1 then set suppressCDR to true and exit
Default set suppressCDR to false
Example 6: Map RAT Type

RAT Network 5G/4G/3G/2G

Maps Radio Access Technology type code to human-readable network type.

Function: MapRATType

Input: ratType (Integer)
Output: networkType (String)

If ratType is 1 then set networkType to UTRAN and exit
If ratType is 2 then set networkType to GERAN and exit
If ratType is 3 then set networkType to WLAN and exit
If ratType is 6 then set networkType to EUTRAN and exit
If ratType is 8 then set networkType to NR and exit
If ratType is 9 then set networkType to EUTRA-NR and exit
Default set networkType to UNKNOWN
